# 持續放量盤整突破追蹤

依使用者短期目標，擴充既有四檔日線工具。免費歷史 API 是日線來源，不假稱盤中即時成交；持續抓取最新已完成日線，盤中訊號留待具有使用權限的行情來源接入。

1. 先新增盤整與突破測試：前 20 日最高最低差／前 20 日平均收盤 <= 12%；收盤超過前高 0.5%；成交量 >= 前 20 日均量 1.5 倍；保留趨勢與暖機條件。參數是研究基線，非獲利證明。
2. 更新 strategy.py、workflow.py；每個門檻有數值與未達原因。
3. monitor.py：每 15 分鐘輪詢四檔；逾時、錯誤個股隔離、保存錯誤狀態、原子寫入，網路失敗不可冒充最新行情；可用 --once 手動更新。
4. 以台灣時區判斷當日日線：18:00 前排除當日資料，以保守方式避免未完成 K 線；不保證來源 18:00 已完成發布。保留來源最新日與已完成資料日。
5. 本機 HTTP server 只綁 localhost；頁面每 60 秒重整，顯示最近更新結果。停止程序即停止追蹤，不建立系統自動啟動。
6. reports/monitor-state.json 保存各股票狀態；reports/events.jsonl 記錄首次觀察與狀態／資料日變化，同一日同狀態不重複提醒。提供狀態事件表，不傳送外部訊息。
7. 驗證：策略與监控整合測試涵蓋錯誤、恢復、去重、時間截點；真實 API --once 與至少兩次循環；本機瀏覽器視覺檢查；文件與 GitHub 同步。
