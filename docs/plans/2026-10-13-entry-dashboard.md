# 第一版進場策略與圖表實作

使用者已授權四檔 AI 名單、進場策略與可視化。先交付不需額外安裝套件的 Python 日線分析及獨立 HTML 研究報告，Streamlit 與持續盤中追蹤保留後續階段。

1. tests/test_strategy.py：先確認測試因缺少策略模組失敗，再實作 strategy.py。
2. strategy.py：20/60 日均線、前 20 日高點、前 20 日均量、14 日 ATR；60 日暖機；當日收盤突破前高、20 日均線高於 60 日均線、收盤高於 20 日均線、成交量至少前均量 1.2 倍才標示候選。
3. build_report.py：讀取本機 FinMind 日線快取，產生 reports/entry-dashboard.html；每檔獨立狀態，不用合成資料替代失敗來源。
4. 圖表顯示收盤、均線、訊號、成交量與來源時間；收盤訊號只形成下一交易日待確認計畫，非當日成交。顯示最後資料日，不宣稱即時。
5. 驗證：Python unittest 全通過；四檔真實資料可解析；瀏覽器開啟報告並检查畫面。
